# Inputs and generated results

`TRENDYv10/31_site_weighted/` contains prepared **inputs** for the R scripts,
generated by `code/TRENDY_extraction_flux_locations.ipynb` (or supplied separately).
The notebook writes per-model annual CSVs, top-level `<MODEL>_site_info.csv`
site-to-grid mappings, `coordinate_audit.csv` and `extraction_manifest.json`.
The audit records coordinates, source units and calendars; the manifest records
configuration, software versions, input paths/sizes/timestamps and output row
counts. These metadata files describe the latest completed extraction run.
The R scripts generate `datasets/` and `figures/` automatically. They overwrite
outputs of the same name and leave other files untouched.

| Script | Figures | CSV tables in `datasets/` |
| --- | --- | --- |
| Figure 1 | `Figure1.pdf` | `Figure1_<MODEL>_<SCENARIO>.csv`, `Figure1_data.csv` |
| Figure 2 | `Figure2.pdf` | `Figure2_alldata.csv` |
| Figure 3 | `Figure3a.png`, `Figure3b.png` | `Figure3a_<MODEL>_S1.csv`, `Figure3b_<MODEL>_S1.csv`, `Figure3a_alldata.csv`, `Figure3b_alldata.csv` |
| Figure 4 | `Figure4.pdf` | `Figure4_<MODEL>.csv`, `Figure4_data.csv`, `<MODEL>_selected_sites_TRENDYv10_3sd_filtered.csv` |

Each completed script also writes `datasets/FigureN_sessionInfo.txt`. All CSVs
have headers and omit R row names. Model/scenario suffixes reflect the selected
parameters (Figure 3 filenames use its configured scenario).

- Figure 1 per-model tables: coordinates, site IDs, matched-row count `n`,
  detrended Pearson `r_detrend_delta` and `p_detrend_delta`. The `n` column counts
  matched rows before finite-pair screening. `Figure1_data.csv` adds `model` and
  `scenario`, including `obs`; observation rows do not have model coordinates.
- Figure 2: coordinates, model, detrended correlation, and response ratio `beta`.
- Figure 3a per-model tables: site-level percentages relative to GPP for `ra`,
  `cWood`, `cLeaf`, and `cRoot`; the aggregate file is in long format.
- Figure 3b per-model tables: fitted percent change for five variables and
  `p_*` binary slope-significance indicators (1 = p < 0.05, 0 otherwise).
  The aggregate file is in long format after complete-case filtering.
- Figure 4: `year`, `model`, and `mean_val_*`, `se_val_*`, `ci_lower_*`,
  `ci_upper_*` for each scenario. Its coordinate files have only `lat`, `lon`,
  representing unique S2 locations after increment outlier filtering.

Obsolete files are not read: in particular `Figure_2.pdf`, old Figure 1 naming
variants, and `_selected_sites_TRENDYv10_post1950_ratio_screened.csv` may remain
from previous runs. The ratio-screened lists use a different selection rule and
must not be substituted for Figure 4's 3-SD lists.

Generated tables/figures are ignored by Git. Archive the final outputs together
with the input data and software environment for the publication release.
